Shopee FBS 货件导入报错分析

上传导入报错的 FBS 文件 + 粘贴导入结果报错，自动定位失败 SKU、原因与处理建议（文件仅在浏览器本地解析，不会上传）

1上传货件文件（Shopee 后台下载的 FBS .xlsx）

拖拽文件到此处，或 点击选择 .xlsx 文件
支持：FBS 官方模板（Inbound Request + SKU Detail 两个 sheet）、通用导入模板

2粘贴导入结果中的报错（可选，建议粘贴）

报错从哪里复制？
平台仓 → 货件计划 → 导入，导入完成后弹出的结果表格里，选中失败行（或全部行）复制，粘贴到上面的输入框。表格两列（货件号、原因）复制后每行一条，可直接使用。

4报错统计

5原因与处理建议

6失败明细 （可直接发给仓配/开发）

7分析报告
